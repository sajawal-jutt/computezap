## Strategy — How to Use This List (Ubersuggest)

1. **Ubersuggest** → "Competitor Analysis" ya "Traffic Analyzer" open karo
2. Competitor URL enter karo (e.g. `calculator.net`)
3. **"Top Pages"** tab → dekho kaunse pages sabse zyada traffic lete hain
4. Us page ka keyword dekho → **KD < 25, Volume > 1K** filter
5. **ComputeZap ke missing pages** identify karo
6. **keyword-research.md** mein add karo aur next batch mein build karo

### Ubersuggest Keyword Gap
- Ubersuggest → "Keyword Gap" tool mein `computezap.com` vs `calculator.net` enter karo
- Woh keywords dikhayega jo competitor rank karta hai lekin hum nahi
- KD 0–25 filter lagao → yeh sab easy targets hain
